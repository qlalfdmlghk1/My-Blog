## 🎨 디자인 분석

- **카드 세로형 전환이 이번 작업의 중심.** `PostCard` 의 바깥 `div` 가 지금 `flex items-start gap-4` 라 가로 배치다. 모바일에서 `flex-col` 로 두고 `CoverImage` 의 `className` 을 전폭(`w-full aspect-[16/9]`)으로, `sm` 이상에서 현행(`sm:w-56`)으로 되돌리는 모바일 퍼스트 방향
- **DOM 순서 주의**: 세로형은 커버가 **위**에 보여야 하는데 현재 `CoverImage` 는 DOM 상 글자 블록 **뒤**에 있다. `order` 로 뒤집되, `h2` 의 stretched link(`after:absolute`)가 커버를 덮지 않는지 확인한다
- **반응형 분기**: Tailwind 기본 브레이크포인트만. 타이포 확대는 `sm`(640) 미만에만
- **최소 지원 폭**: 360px
- **헤더 높이**: `3.5rem` 유지 — 바꾸면 `PostToc` 의 `top-20` 과 `globals.css` 의 `scroll-margin-top` 두 곳을 함께 고쳐야 한다(`SiteHeader.tsx` 주석)
- **다크 모드**: 기존 토큰·팔레트 변수가 따라오는 수준까지
- **터치 타깃**: 최소 44×44 기준으로 `TagChip`·`CategoryBadge`·`CategoryNav` 탭 점검
- **재사용**: `PostCard` · `CoverImage` · `CategoryNav` · `TagChip` · `CategoryBadge` · `Pagination`
- **신규 컴포넌트**: 없음 — 전부 기존 컴포넌트의 클래스 조정으로 처리한다
