### 📌 구현 중 판단

- **커버를 DOM 에서 글자보다 앞으로 옮겼다.** 세로 배치에서 위에 놓기 위해서이기도 하지만, 진짜 이유는 stretched link 의 겹침 순서다 — 제목 링크의 `::after` 와 커버는 둘 다 위치 지정 요소라 z-index 없이 DOM 순서대로 쌓인다. 커버가 뒤에 있으면 커버가 링크를 덮어 **그 자리만 눌리지 않는데**, 세로 배치에서는 그 면적이 카드의 절반이다. (가로 배치에서도 원래 커버는 눌리지 않았다 — 이번에 같이 고쳐졌다)
- **메타 순서 변경은 데스크톱에도 반영된다.** plan.md 의 Out of Scope("데스크톱 레이아웃 변경")와 형식상 충돌하지만, 순서를 폭으로 가르려면 같은 내용을 두 벌 적어야 해 한쪽만 고치는 날이 온다. In Scope 항목("메타 순서 — 검토 후 적용")을 우선해 양쪽 같은 순서로 두었다. **원치 않으면 되돌린다.**
- **본문 확대는 `.reading .md` 로 한정했다** — `.md` 에 바로 걸면 관리자 발행 미리보기와 사전 화면까지 따라 커진다.

### 🔎 착수 전 유의

- `PostCard` 의 `CoverImage` 는 DOM 상 글자 블록 **뒤**에 있다. 세로형에서 커버를 위로 올리려면 `order` 로 뒤집되, `h2` 의 stretched link(`after:absolute`)가 커버를 덮지 않는지 확인
- 헤더 높이 `3.5rem` 을 바꾸면 `PostToc` 의 `top-20` 과 `globals.css` 의 `scroll-margin-top` 을 함께 고쳐야 한다
- 열린 항목: 현행 모바일에서 실제로 거슬렸던 증상 목록이 없다(기획 검수 ⚠️7). 작업 중 떠오르면 `/note` 로 남길 것
