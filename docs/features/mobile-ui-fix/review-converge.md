## Round 2에서 확정된 중요 검증

- **`rem` → `em` 전환은 안전하다.** 최대 회귀 후보였으나, `.md` 자신이 `font-size: 1rem` 으로 절대 기준을 박고 있어 조상 체인과 무관하게 항상 루트 16px 기준으로 풀린다. 관리자 미리보기(`PostEditor` · `PublishReview`) 조상 체인에 `font-size` 를 거는 요소가 없음을 실제로 확인했고, 데스크톱 px 값도 전부 동일하다(h2 22.4 · h3 18.4 · h4 16 · table 14.4 · pre 13.6).
- **`z-[1]` 의 쌓임 맥락 분석도 확인됐다.** 글자 `div` 와 `article` 이 쌓임 맥락을 만들지 않아 `::after` 가 `order` 와 무관하게 항상 커버 위에 온다. `TagChip`(`z-10`)은 그 위 유지, `CategoryBadge` 는 `span` 이라 덮여도 무해.
- **헤더 높이 불변 확인.** `py-3` + `text-sm`(20px) = 44px 가 `h-14`(56px) 안에서 흡수되어 `PostToc` 의 `top-20` · `globals.css` 의 `scroll-margin-top` 연쇄가 없다.
