## 🎨 디자인 분석

- **레퍼런스**: toss.tech 글 상세 (모바일 스크린샷) — 커버가 **제목 위**에 본문 폭 가득, 모서리 둥글게, 그 아래 제목 → 작성자 → 날짜
- **배치**: `<main>` 의 첫 칼럼(`min-w-0`) 안, `<header>` 바로 위. 본문 폭(`max-w-prose` / xl 에서 44rem)을 그대로 따른다 — 목차 칼럼까지 넓히지 않는다
- **비율·모서리**: 목록 카드와 같은 `aspect-[16/9]` · `rounded-xl` 로 두어 "같은 그림"으로 읽히게 한다
- **반응형 분기**: 별도 분기 없음 (폭은 부모를 따른다)
- **재사용 컴포넌트**: `src/components/CoverImage.tsx` — `priority` 로 LCP 이미지 우선 로딩, `zoomOnHover` 는 쓰지 않는다
- **신규 컴포넌트**: 없음

## 🛠️ 접근 방식

- `app/posts/[slug]/page.tsx` 에서 `post.coverImage` 가 있을 때만 `<CoverImage>` 를 `<header>` 위에 렌더한다
- `CoverImage` 컴포넌트 자체는 고치지 않는다 — 목록·히어로·발행 검토 화면으로 번질 여지를 없앤다
- `category` 는 넘기지 않는다 — 사진 경로(`src` 있음)는 팔레트를 쓰지 않는다
- 목차 접기 상태의 정본은 `<html>` 의 `.toc-collapsed` 클래스 — `ThemeToggle` 과 같은 구조. `layout.tsx` 인라인 스크립트가 첫 페인트 전에 localStorage(`toc`)에서 복원하고, 폭·아이콘은 Tailwind `toc-collapsed:` 변형(`tailwind.config.ts` 플러그인)으로만 그린다 → 깜빡임 없음
- 클라이언트 JS 는 단추 하나(`TocCollapseToggle`)뿐. `PostToc` 는 서버 컴포넌트 유지
- 두 칸 합을 59.5rem 으로 맞춘다: 펼침 `44rem + 2.5 + 13rem` / 접힘 `55rem + 2.5 + 2rem` — 화면 좌우 가장자리 불변
