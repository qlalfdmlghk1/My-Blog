- 커버 URL 이 깨지면 16:9 빈 판이 남음 (🧪) — 사유: **제품 판단 필요** (숨길지 허용할지). 공용 `CoverImage` 는 건드리지 않기로 한 결정과 얽힘
- `'toc'` · `'toc-collapsed'` 문자열이 세 파일에 흩어짐 (🏗️) — 사유: 과한 추상화. 기존 `'theme'` / `.dark` 와 같은 패턴이고 교차 참조 주석 있음
- `TocSummary` 의 `count?` optional (🏗️ 🧑‍💻) — 사유: 취향성
- aria-expanded 가 하이드레이션 후 보정 (🧪) — 사유: `ThemeToggle` 과 같은 구조, 시각 상태는 CSS 로 맞음
- 13rem · 55rem · 2rem 테마 토큰화 (🧑‍💻) — 사유: 과한 추상화
- 펼치는 300ms 동안 2rem 칸에 스크롤바가 잠깐 겹침 (Round 2, 🧑‍💻 🧪) — 사유: 일시적 표시 문제, 리뷰어도 수용 권장. 고치려면 JS 타이밍이 필요해 "CSS 로만 그린다" 원칙과 충돌
