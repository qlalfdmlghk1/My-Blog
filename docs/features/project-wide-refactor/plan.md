## 🎨 디자인 분석

- **반응형 분기**: 기존 `ListShell` · `SiteSidebar` 레이아웃 규칙을 그대로 따름 (별도 브레이크포인트 신설 없음)
- **재사용 컴포넌트**: `src/components/ListShell.tsx` · `PostToc.tsx` · `CategoryBadge.tsx` · `TagChip.tsx`
- **신규 컴포넌트**: 용어 사전 목록/항목 컴포넌트 (`src/components/` 하위), 본문 용어 링크 렌더링 처리

## 🛠️ 접근 방식

- **용어 사전**: Firestore `glossary` 컬렉션 신설 + `/admin/glossary` CRUD. 카테고리와 같은 규약(문서 ID = slug)을 쓴다. 공개 사전은 `/glossary`
- **본문 연결**: 마크다운 렌더 시점 자동 링크 — 글 한 편당 첫 등장 한 번. 제목·기존 링크 안에서는 걸지 않는다
- **slug**: 번역이 아니라 로마자 표기(RR). `lib/romanize.ts` 신설, `toAsciiSlug` 를 `PostEditor` 가 쓴다. 앵커용 `slugify` 는 그대로 유지
- **드래그 하이라이트**: `--select-*` 토큰 + 전역 `::selection` (`src/app/globals.css`)

> 결정 근거는 `progress.md` 의 결정 로그 참고.
