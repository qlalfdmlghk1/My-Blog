# ui-refactor — Troubleshoot

## 스크롤바가 생길 때마다 본문이 좌우로 들썩였다 (2026-09-17)

**증상**

홈에서 캐러셀을 넘기거나 카테고리 화면을 오가면 화면 전체가 좌우로 몇 px 밀렸다. 콘텐츠 길이가 뷰포트보다 짧아졌다 길어졌다 할 때마다 반복됐다.

**원인**

Windows 의 클래식 스크롤바는 15px 폭을 차지한다. 콘텐츠가 뷰포트보다 길어지면 스크롤바가 생기면서 뷰포트 폭이 15px 줄고, `mx-auto` 로 가운데 정렬된 콘텐츠가 그 절반만큼 왼쪽으로 밀린다. 다시 짧아지면 스크롤바가 사라지며 되돌아온다. macOS 의 오버레이 스크롤바는 폭을 차지하지 않아 거기서는 재현되지 않는다.

**해결**

`globals.css` 의 `html` 에 `scrollbar-gutter: stable` 을 추가했다. 스크롤바가 없을 때도 그 자리를 비워 두어 뷰포트 폭이 바뀌지 않는다.

**대가**

스크롤할 것이 없는 짧은 화면에서도 오른쪽에 스크롤바 폭만큼 빈 띠가 남는다. `overflow-y: scroll` 로 항상 스크롤바를 그리는 방법도 있지만, 그쪽은 스크롤할 것이 없는데 비활성 스크롤바가 보여 더 어색하다.
