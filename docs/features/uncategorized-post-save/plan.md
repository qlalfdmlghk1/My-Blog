> ⚠️ 착수 후 정정: 여기서 "카테고리 없음"은 **소분류의 '분류 없음'** 을 뜻한다.
> 카테고리는 계속 필수이고, 소분류만 선택 사항이다.

## 🎯 작업 목적

카테고리를 고른 뒤 소분류를 '분류 없음'으로 두어도 글을 저장할 수 있도록 하기 위해

## 🛠️ 접근 방식

- '분류 없음'은 문서가 없는 자리라 예약 slug `_none`(`LOOSE_SUBCATEGORY`)을 주소에만 쓴다. 저장값은 빈 문자열 그대로. 관리 화면 `slugify`가 `_`를 `-`로 바꾸므로 사람이 만든 소분류와 겹칠 수 없다
- 칩은 looseCount > 0 일 때만 노출. 목록·메타데이터·ISR revalidate 경로가 같은 상수를 공유
- `TagChip` 높이를 `h-6`으로 고정 — 여백 기반 높이가 글꼴 기준선 차이로 어긋났다
